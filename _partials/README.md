# `_partials/` — общие фрагменты страниц

Здесь хранится **единственный источник правды** для шапки, футера и скриптов сайта.

## Файлы

| Файл | Что это |
|---|---|
| `nav.html` | Шапка `<nav>` + мобильное меню `<div class="mobile-menu">` |
| `footer.html` | Подвал `<footer>` со всеми колонками и социальными сетями |
| `scripts.html` | Плавающая WhatsApp-кнопка + подключение `i18n.js` и `script.js` |

## Как править

1. Открой нужный файл в `_partials/` и поправь HTML.
2. Из корня репозитория запусти:
   ```bash
   python build.py
   ```
3. Скрипт пройдётся по всем страницам и заменит содержимое между маркерами:
   ```html
   <!-- nav:start -->
       (тут будет содержимое _partials/nav.html)
   <!-- nav:end -->
   ```
4. Закоммить изменения и `_partials/`, и сами страницы.

## Полезные команды

```bash
python build.py            # обновить все страницы
python build.py --check    # сухой прогон, только показать что изменится
python build.py --verbose  # подробный вывод
```

## Если добавляешь новую страницу

В новом `index.html` поставь три пары маркеров — где должна быть шапка/футер/скрипты:

```html
<body>

<!-- nav:start -->
<!-- nav:end -->

<!-- ... содержимое страницы ... -->

<!-- footer:start -->
<!-- footer:end -->

<!-- scripts:start -->
<!-- scripts:end -->

</body>
```

Затем `python build.py` — и шапка с футером появятся автоматически.

## CI

В CI можно повесить проверку, что никто не отредактировал страницу мимо partial:

```bash
python build.py --check
```

Возвращает exit code 1, если хоть одна страница рассинхронизирована.
